# Pedro Henrique Rodrigues Cardoso - Portfolio

## Sobre o Projeto

Este projeto é um portfólio profissional desenvolvido para apresentar a trajetória, projetos, habilidades e objetivos de carreira de Pedro Henrique Rodrigues Cardoso, um Engenheiro de Dados em início de carreira. O portfólio é construído utilizando as tecnologias mais modernas e segue as melhores práticas de desenvolvimento.

## Tecnologias Utilizadas

- **Next.js 15**: Framework React para construção de aplicações web.
- **React**: Biblioteca JavaScript para construção de interfaces de usuário.
- **TypeScript**: Superset do JavaScript que adiciona tipagem estática.
- **Tailwind CSS**: Framework CSS para estilização rápida e responsiva.
- **Framer Motion**: Biblioteca para animações em React.
- **Lucide Icons**: Conjunto de ícones para uso em interfaces.

## Estrutura do Projeto

A estrutura do projeto é organizada da seguinte forma:

```
src/
 ├─ app
 ├─ components
 ├─ sections
 ├─ data
 ├─ hooks
 ├─ lib
 └─ assets
```

## Seções do Portfólio

1. **Hero**: Apresenta o nome, foto e áreas de atuação.
2. **Sobre Mim**: Descrição da trajetória profissional.
3. **Timeline Profissional**: Histórico educacional e profissional.
4. **Projeto Acadêmico**: Detalhes sobre o projeto "Preciosos Laços".
5. **Habilidades**: Visualização das habilidades com barras de progresso.
6. **Projetos Corporativos**: Descrição de projetos realizados na Vivo.
7. **Dashboard de Impactos**: Exibição de métricas de impacto.
8. **Compartilhamento de Conhecimento**: Participação em eventos.
9. **Objetivo Profissional**: Declaração de objetivos de carreira.
10. **Contato**: Informações de contato.

## Funcionalidades

- Tema escuro e claro.
- Animações suaves e interativas.
- Indicador de progresso de rolagem.
- Efeito parallax nas seções.
- Cards interativos para projetos.
- Filtragem de projetos por tecnologia.

## Como Executar o Projeto

1. Clone o repositório:
   ```
   git clone <URL_DO_REPOSITORIO>
   ```

2. Navegue até o diretório do projeto:
   ```
   cd pedro-portfolio
   ```

3. Instale as dependências:
   ```
   npm install
   ```

4. Execute o projeto:
   ```
   npm run dev
   ```

5. Acesse o portfólio em `http://localhost:3000`.
